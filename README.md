# Grocery List App

A simple and visually engaging grocery list app built as a personal fun project to make shopping more organized and easier to track.

## Overview

This project lets users add grocery items, mark them as completed, delete items from the list, and monitor shopping progress through a live progress bar. The interface is designed with a bright, playful style and a responsive layout for desktop and mobile screens.

## Features

- Add grocery items to a shopping list
- Mark items as completed with a checkbox
- Remove items from the list
- Track progress with a live percentage and item counter
- View a responsive, mobile-friendly design

## Tech Stack

- HTML5
- CSS3
- JavaScript
